## سجل العوائق المفتوحة
- [ ] مفتاح OpenAI إنتاجي: يلزم ضبط `OPENAI_API_KEY` و`OPENAI_MODEL` في Render لاختبار التوليد الحي.
- [ ] حسابات منصات التواصل: يلزم إنشاء تطبيقات المطورين لكل منصة وتوفير OAuth client ID/secret وredirect URI والموافقات المطلوبة.
- [ ] تخزين الملفات: تم تحديد Cloudflare R2 كمزود مناسب، لكن إنشاء الحاوية عبر API أعاد 403/10042 لأن R2 غير مفعّل للحساب بعد. يجب تفعيل R2 مرة واحدة من Cloudflare Dashboard ثم إنشاء bucket خاص (دون تفعيل الوصول العام) وإضافة بيانات S3 API إلى Render؛ Redis ليس مخزناً للملفات.
- [ ] الأتمتة المستمرة: حساب QStash المجاني متاح في منطقتي EU وUS ولا توجد جداول حالية؛ يلزم بناء endpoint يتحقق من توقيعات QStash ويدعم idempotency وسجل التشغيل قبل إنشاء أي schedule أو نشر رسائل.
- [ ] تعدد المستخدمين: يتطلب نقل الدخول من مفتاح مالك مشترك إلى هوية مستخدم وجلسات ومراجعة Membership على كل استعلام وطفرة.
- [ ] ضمانات التشغيل: يلزم إعداد نسخ احتياطي مجدول واختبار استعادة ومراقبة وتنبيهات واختبارات E2E.
