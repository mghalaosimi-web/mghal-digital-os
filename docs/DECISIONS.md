# سجل قرارات التصميم (ADR Index)

## ADR-0001: المنتج مساحة عمل رقمية أوسع من جدولة المنشورات
- **الحالة:** مقبول.
- **السياق:** نطاق المنتج يشمل الهوية والمحتوى والمشاريع والمعرفة والأتمتة والتحليلات.
- **القرار:** بناء MGHAL Digital OS كمنتج مستقل. لا يُفترض أن Postiz هو الأساس؛ يمكن تقييمه لاحقاً كمصدر إلهام أو مكون منفصل بعد مراجعة الكود والترخيص وحدود المنتج.
- **النتيجة:** لا يُربط جوهر النظام بجدولة النشر أو بمزود واحد.

## ADR-0002: Modular Monolith
- **الحالة:** مقبول.
- **القرار:** البدء بتطبيق واحد وحدود وحدات واضحة بدلاً من microservices.
- **النتيجة:** نشر وتشغيل أبسط، مع إمكانية فصل workers أو خدمات مستقلة عند وجود مبرر مقاس.

## ADR-0003: Next.js وTypeScript وPostgreSQL
- **الحالة:** مقبول مبدئياً.
- **القرار:** Next.js App Router وReact وTypeScript للواجهة وRoute Handlers، وPostgreSQL لتخزين البيانات.
- **النتيجة:** مكدس موحد للمرحلة التأسيسية. لا يعني ذلك أن قاعدة بيانات إنتاجية قد أُنشئت.

## ADR-0004: Prisma ORM 7
- **الحالة:** مقبول.
- **السياق:** تم العثور على ثغرات High في شجرة Prisma 6.19.3 أثناء فحص npm audit.
- **القرار:** الانتقال إلى Prisma 7.10.1 مع prisma-client generator وPostgreSQL driver adapter وPrisma Config.
- **النتيجة:** يتطلب Node.js 20.19+ أو 22.12+ أو 24+، وتوليد العميل قبل typecheck/build. لا تُطبق migrations قبل توفير قاعدة بيانات واختبارها.

## ADR-0005: مفتاح مالك مؤقت لواجهات API
- **الحالة:** مؤقت وغير مناسب للإطلاق العام.
- **القرار:** استخدام Bearer token خادمي بطول لا يقل عن 32 محرفاً لحماية المسارات الإدارية خلال التطوير.
- **النتيجة:** لا يوجد تسجيل دخول أو جلسات أو RBAC حقيقي حتى الآن. يمنع وضع المفتاح في المتصفح أو NEXT_PUBLIC_*.

## ADR-0006: لا إجراءات خارجية بلا موافقة
- **الحالة:** مبدأ منتج معتمد.
- **القرار:** لا نشر أو إرسال أو حذف أو تنفيذ إجراء خارجي بواسطة AI/automation دون موافقة صريحة قابلة للتدقيق.
- **النتيجة:** يجب أن تتضمن الوحدات المستقبلية approval state وaudit trail وidempotency.
