# نطاق المنتج والمتطلبات

## 1. الهدف

MGHAL Digital OS مساحة عمل شخصية موحّدة تقلل التشتت بين إدارة الهوية المهنية، إنتاج المحتوى، المشاريع، المعرفة، والأتمتة. المنتج ليس مجرد مجدول منشورات؛ بل نظام تشغيل رقمي قابل للتوسع مع واجهة تحكم ومصادر بيانات واضحة.

## 2. المستخدمون والأدوار

- **Owner:** مالك مساحة العمل، يضبط الإعدادات ويعتمد الإجراءات الحساسة.
- **Admin:** يدير الإعدادات والمستخدمين عند تفعيل تعدد المستخدمين.
- **Editor:** ينشئ ويحرر المحتوى والمشاريع دون امتلاك أسرار التكامل.
- **Viewer:** قراءة فقط.

يبدأ الإصدار الأول بمساحة عمل فردية، مع تصميم قاعدة البيانات لتجنب إعادة الهيكلة عند إضافة فرق لاحقاً.

## 3. الوحدات

### الهوية الرقمية
الملف التعريفي، السيرة المهنية، المهارات، الأهداف، الروابط، الأصول المعتمدة، دليل النبرة والأسلوب.

### المحتوى
الأفكار، المسودات، المحتوى متعدد القنوات، التقويم، حالات المراجعة، الموافقات، النشر المجدول، وسجل النتائج. يجب فصل المحتوى الأصلي عن تكييفه لكل قناة.

### المشاريع والمهام
المشاريع، المهام، الأولوية، الحالة، التواريخ، التبعيات، التعليقات، المرفقات، وسجل النشاط.

### المعرفة
ملاحظات ومصادر وروابط وملفات ووسوم. كل إجابة مولدة من المعرفة يجب أن تحفظ مراجعها ومصدرها.

### الأتمتة
تعريف تدفقات العمل ومشغلاتها وخطواتها، حدود التشغيل، محاولات التنفيذ، الموافقات، ومنع التكرار عبر مفاتيح idempotency.

### الذكاء الاصطناعي
مساعدون متخصصون للمحتوى والتخطيط والبحث وتحليل المشاريع. يجب تقييد الأدوات بحسب الدور والوحدة، وتسجيل النموذج والأدوات والمصادر المستخدمة دون تخزين أسرار.

### التحليلات
لوحة مؤشرات، تقدم المشاريع، انتظام النشر، أداء القنوات، ومعدلات نجاح الأتمتة.

## 4. قصص المستخدم ذات الأولوية

1. بصفتي مالك النظام، أريد إعداد هويتي ونبرة المحتوى مرة واحدة كي تستخدمها الوحدات عند إنشاء المسودات.
2. أريد تحويل فكرة إلى مسودة قابلة للتحرير مع حفظ المصدر وسياق القناة.
3. أريد تحويل مخرجات المحتوى إلى مهام ومواعيد دون تكرار البيانات.
4. أريد رؤية جميع مشاريعي ومهامي في لوحة واحدة.
5. أريد تشغيل أتمتة تجريبية ومعرفة كل خطوة ونتيجتها.
6. أريد أن تتوقف أي عملية نشر أو إرسال حتى أعتمدها صراحة.
7. أريد تصدير بياناتي وحذفها وفق سياسة واضحة.

## 5. متطلبات الجودة

- دعم العربية وRTL والإنجليزية.
- تصميم متجاوب وإمكانية الوصول بلوحة المفاتيح.
- أداء جيد مع pagination وعمليات بحث مفهرسة.
- سجلات تدقيق للعمليات الحساسة.
- نسخ احتياطي واستعادة موثقان.
- معالجة أخطاء موحدة ورسائل مفهومة.
- اختبارات للوحدات والتكامل والمسارات الحرجة.

## 6. خارج النطاق في الإصدار الأول

- النشر التلقائي غير المراجع.
- تنفيذ أوامر shell عشوائية بواسطة الوكلاء.
- تخزين كلمات المرور أو مفاتيح API كنص صريح.
- تعدد المؤسسات والفوترة قبل استقرار المنتج الأساسي.
