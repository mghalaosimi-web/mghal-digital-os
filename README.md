# MGHAL Digital OS

منظومة رقمية شخصية لإدارة الهوية المهنية والحضور الرقمي والمحتوى والمشاريع والمعرفة وسير العمل، مع بنية قابلة للتوسع لإضافة الذكاء الاصطناعي والأتمتة.

> **الحالة الحالية:** تطبيق Next.js 16 / React 19 / TypeScript بواجهة عربية RTL أولية، ومخطط PostgreSQL عبر Prisma، وواجهات API أولية للمساحات والمشاريع والمهام والمعرفة والمحتوى، وحراسة خادمية بمفتاح مالك، وسجل تدقيق، وفحوص CI للبناء والتحقق من الأنواع. هذه مرحلة تأسيس هندسي وليست نسخة إنتاجية مكتملة.

## الرؤية

إنشاء مركز قيادة موحد: تدخل المعلومة مرة واحدة، ثم تساعدك المنظومة على تنظيمها وتحويلها إلى مهام ومحتوى وقرارات ومخرجات قابلة للمراجعة، مع إبقاء النشر الخارجي والإجراءات الحساسة تحت موافقة صريحة.

## المجالات الأساسية

- **Identity:** ملف مهني، أهداف، نبرة صوت، روابط، ومكتبة أصول معتمدة.
- **Content Studio:** أفكار، تقويم تحريري، مسودات، مراجعات، قنوات، وسجل نشر.
- **Projects:** مشاريع، مهام، أولويات، مواعيد، ملاحظات، وقرارات.
- **Knowledge:** مصادر وملفات وملاحظات مع بحث واسترجاع موثوق.
- **Automation:** مشغلات، إجراءات، موافقات، سجلات تنفيذ، وإعادة محاولة آمنة.
- **AI Workspace:** مساعدين متخصصين بصلاحيات محددة ومراجع للمصادر.
- **Analytics:** قياس التقدم والأداء ومؤشرات الحضور الرقمي.

## مبادئ أساسية

1. الخصوصية والأمان افتراضياً؛ لا أسرار في Git.
2. لا نشر أو إرسال أو حذف خارجي دون موافقة واضحة قابلة للتدقيق.
3. كل عملية آلية لها سجل حالة ونتيجة وسبب فشل.
4. صلاحيات أقل ما يمكن، وفصل بيانات مساحات العمل.
5. الذكاء الاصطناعي يقترح ويجهز؛ والإنسان يعتمد الإجراءات ذات الأثر الخارجي.
6. واجهات متاحة ومتجاوبة وتدعم العربية وRTL من البداية.
7. لا ندعي نجاح اختبار أو تكامل قبل تشغيله فعلياً.

## البنية المنفذة حالياً

- Next.js App Router مع React وTypeScript.
- Prisma schema يستهدف PostgreSQL ويعرّف المستخدمين والعضويات ومساحات العمل والمشاريع والمهام والمعرفة والمحتوى وسجل التدقيق.
- API أولية للتحكم بالمساحات والمشاريع والمهام والمعرفة والمحتوى.
- تحقق مدخلات باستخدام Zod.
- حماية API الإدارية بواسطة `OWNER_API_TOKEN` محفوظ على الخادم فقط.
- GitHub Actions للتحقق من Prisma Client وTypeScript وproduction build.

## ما لم يكتمل بعد

- لا توجد مصادقة مستخدمين وجلسات أو صلاحيات عضوية فعلية؛ مفتاح المالك الحالي حل تأسيسي محدود.
- لا يوجد اتصال قاعدة بيانات إنتاجية مؤكد أو migration أولي ملتزم بالمستودع.
- الواجهة الحالية لوحة تأسيسية وليست واجهات CRUD متصلة بالبيانات.
- لا توجد تكاملات اجتماعية أو مزود AI أو محرك أتمتة أو workers.
- يلزم استكمال الاختبارات، الفحص الأمني، المراقبة، النسخ الاحتياطي، والنشر.

**لا تعرض API الإدارية للإنترنت العام قبل إضافة المصادقة والصلاحيات وتحديد المعدل.** لا تضع `OWNER_API_TOKEN` في المتصفح أو أي متغير `NEXT_PUBLIC_*`.
