## العوائق والاعتماديات الخارجية

- **AI:** يلزم إعداد مفتاح ونموذج مزود AI في متغيرات Render. لا نضع الأسرار في المستودع.
- **التواصل الاجتماعي:** يلزم تطبيق مطور معتمد وOAuth credentials وموافقات المنصات لكل قناة.
- **الملفات:** Cloudflare R2 لم يتم تفعيله للحساب؛ لن يتم دفع أي مبلغ لتفعيله. نحتاج خيار تخزين دائم مجاني أو حل داخلي محدود الحجم.
- **الأتمتة:** لا تنشأ جداول QStash قبل تنفيذ التحقق من التوقيع وidempotency وسجل التنفيذ.
- **المستخدمون المتعددون:** المخطط الأساسي موجود، لكن لا يجوز فتح تسجيل المستخدمين قبل اكتمال المصادقة وتفويض الوصول واختبارات العزل.

## قيود تشغيلية

- Render يعمل حالياً على الخطة المجانية وقد ينام عند عدم الاستخدام.
- لا توجد حالياً خدمة ملفات دائمة أو worker منفصل.
- لا يتم إنشاء موارد أو اشتراكات مدفوعة دون موافقة صريحة.
