# خارطة الطريق

الحالات تعكس ما هو موجود في المستودع بعد فحص التنفيذ، لا مجرد نية مستقبلية.

## المرحلة 0 — التأسيس البرمجي
- [x] إنشاء المستودع ووثائق المنتج.
- [x] إنشاء تطبيق Next.js App Router وTypeScript.
- [x] واجهة تأسيسية عربية RTL.
- [x] إعداد PostgreSQL schema عبر Prisma.
- [x] إعداد Prisma 7 وPostgreSQL adapter.
- [x] إضافة lockfile واستخدام npm ci.
- [x] إعداد lint واختبارات وحدات أولية.
- [x] إعداد CI للفحص الأمني والاختبارات وtypecheck وbuild.

## المرحلة 1 — أساس البيانات وواجهات API
- [x] نماذج Workspace وMembership وProject وTask وKnowledgeItem وContentItem وAuditEvent في Prisma schema.
- [x] واجهات API أولية للمساحات والمشاريع والمهام والمعرفة والمحتوى.
- [x] حراسة API بمفتاح مالك خادمي مؤقت.
- [x] التحقق من JSON وContent-Type وحد حجم الطلب.
- [x] جعل الكتابة وسجل التدقيق عملية ذرية في المعاملات.
- [ ] توفير PostgreSQL مخصص وإنشاء أول migration وتطبيقه في بيئة اختبار.
- [ ] مصادقة حسابات وجلسات آمنة واستعادة وصول.
- [ ] RBAC حقيقي وعزل workspace مثبت بالاختبارات.
- [ ] rate limiting ومعالجة أخطاء موحدة.
- [ ] اختبارات تكامل للـ API وقاعدة البيانات.

## المرحلة 2 — تجربة إدارة العمل
- [ ] ربط لوحة الواجهة ببيانات API الحقيقية.
- [ ] CRUD مكتمل للمشاريع والمهام مع البحث والترشيح والترقيم.
- [ ] نشاط موحد وسجل تغييرات قابل للعرض.
- [ ] ملفات ومرفقات مع تخزين آمن وروابط موقعة.

## المرحلة 3 — استوديو المحتوى
- [ ] إدارة أفكار ومسودات ونسخ متعددة للقنوات.
- [ ] تقويم تحريري ومراجعات وموافقات.
- [ ] تكاملات منصات رسمية بعد دراسة APIs وسياساتها.
- [ ] نشر تجريبي بموافقة صريحة وسجل نتائج؛ لا يوجد نشر حقيقي الآن.

## المرحلة 4 — المعرفة والذكاء الاصطناعي والأتمتة
- [ ] مصادر معرفة وفهرسة وبحث.
- [ ] واجهة موحدة لمزودي AI مع إدارة تكاليف وحدود.
- [ ] مساعدون متخصصون بصلاحيات وأدوات مقيدة.
- [ ] queue/workers وسجل تشغيل وإعادة محاولة آمنة.
- [ ] موافقات قبل الإجراءات الخارجية ومقاومة prompt injection.

## المرحلة 5 — الجودة والإطلاق
- [ ] اختبارات E2E وأمن وعزل بيانات.
- [ ] مراقبة وتنبيهات ونسخ احتياطي واختبار استعادة.
- [ ] مراجعة أداء وإمكانية وصول وتجربة هاتف.
- [ ] سياسة خصوصية واحتفاظ وحذف وتصدير.

## الأولوية التالية

الأولوية ليست إضافة تكاملات اجتماعية الآن؛ بل إكمال قاعدة البيانات والمigrations والمصادقة وعزل مساحات العمل، ثم ربط الواجهة ببيانات حقيقية.
