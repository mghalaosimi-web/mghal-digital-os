# MGHAL Digital OS

منظومة رقمية شخصية مستقلة لإدارة الهوية المهنية والحضور الرقمي والمحتوى والمشاريع والمعرفة وسير العمل، مع طبقة ذكاء اصطناعي قابلة للتوسع.

> **الحالة الحالية:** أساس التطبيق والواجهة العربية RTL ومخطط PostgreSQL وواجهات API الأولية موجودة. تمت إضافة اختبارات وحدات وCI قابل لإعادة الإنتاج. لا توجد بعد مصادقة حسابات وجلسات كاملة، ولا migration أولية مطبقة على قاعدة بيانات حقيقية، ولا تكاملات نشر أو ذكاء اصطناعي عاملة.

## الرؤية

إنشاء مركز قيادة موحد: تدخل المعلومة مرة واحدة، ثم تساعدك المنظومة على تنظيمها وتحويلها إلى مهام ومحتوى وقرارات ومخرجات قابلة للمراجعة، مع إبقاء النشر الخارجي والإجراءات الحساسة تحت موافقة صريحة.

## المجالات الأساسية

- **Identity:** ملف مهني، أهداف، نبرة صوت، روابط، ومكتبة أصول معتمدة.
- **Content Studio:** أفكار، تقويم تحريري، مسودات، مراجعات، قنوات، وسجل نشر.
- **Projects:** مشاريع، مهام، أولويات، مواعيد، ملاحظات، وقرارات.
- **Knowledge:** مصادر وملفات وملاحظات مع بحث واسترجاع موثوق.
- **Automation:** مشغلات، إجراءات، موافقات، سجلات تنفيذ، وإعادة محاولة آمنة.
- **AI Workspace:** مساعدين متخصصين بصلاحيات محددة ومراجع للمصادر.
- **Analytics:** قياس التقدم والأداء ومؤشرات الحضور الرقمي.

## ما هو موجود الآن

- Next.js App Router وReact وTypeScript مع واجهة أولية عربية RTL.
- PostgreSQL schema عبر Prisma ORM 7 وPostgreSQL driver adapter.
- API أولية للمساحات والمشاريع والمهام والمعرفة والمحتوى.
- حراسة API بمفتاح مالك خادمي مؤقت، وفحوص مدخلات JSON.
- تسجيل AuditEvent داخل المعاملة نفسها لعمليات الكتابة المدعومة.
- اختبارات وحدات للحراسة الأمنية وقراءة JSON.
- CI ينفذ التثبيت المقفل والتوليد والفحص الأمني وlint والاختبارات وtypecheck وbuild.

## ما لم يكتمل بعد

- تسجيل الدخول والجلسات وإدارة المستخدمين وRBAC حقيقي.
- إعداد قاعدة بيانات فعلية وإنشاء أول migration والتحقق من النسخ الاحتياطي والاستعادة.
- ربط لوحة الواجهة ببيانات API الحقيقية.
- اختبارات تكامل وE2E واختبارات عزل مساحات العمل.
- rate limiting ومراقبة وتشغيل workers/queue.
- تكاملات منصات المحتوى والنشر الفعلي.
- مزود ذكاء اصطناعي، استرجاع معرفي، وموافقات تنفيذ.
- التحليلات والتقارير.

## مبادئ أساسية

1. الخصوصية والأمان افتراضياً؛ لا أسرار في Git.
2. لا نشر أو إرسال أو حذف خارجي دون موافقة واضحة قابلة للتدقيق.
3. كل عملية آلية لها سجل حالة ونتيجة وسبب فشل.
4. صلاحيات أقل ما يمكن، وفصل بيانات مساحات العمل.
5. الذكاء الاصطناعي يقترح ويجهز؛ والإنسان يعتمد الإجراءات ذات الأثر الخارجي.
6. واجهات متاحة ومتجاوبة وتدعم العربية وRTL من البداية.
7. لا ندعي نجاح اختبار أو تكامل قبل تشغيله فعلياً.
