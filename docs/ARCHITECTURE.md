# المعمارية التقنية المقترحة

## الحالة

هذه وثيقة تصميم مبدئية وليست وصفاً لبنية منفذة. المستودع بدأ فارغاً تقريباً؛ لذلك لا يوجد إطار عمل أو قاعدة بيانات معتمدة بعد.

## التوجه

اعتماد Modular Monolith في البداية بدلاً من microservices. هذا يقلل كلفة التشغيل ويُبقي حدود الوحدات واضحة، مع إمكانية فصل الخدمات عند وجود حاجة مثبتة.

## الطبقات

1. **Presentation:** واجهة عربية RTL، صفحات ولوحات ومكونات.
2. **Application:** حالات الاستخدام، التحقق من المدخلات، وسياسات الصلاحيات.
3. **Domain:** الكيانات وقواعد العمل والأحداث.
4. **Infrastructure:** قاعدة البيانات، التخزين، البريد، مزودات الذكاء الاصطناعي، ومنصات النشر.
5. **Workers:** تنفيذ المهام الطويلة والأتمتة خارج طلبات الويب، مع queue وسجل محاولات.

## حدود الوحدات

- identity
- content
- projects
- knowledge
- automations
- ai
- integrations
- analytics
- audit

كل وحدة تملك منطقها وواجهات خدماتها؛ يمنع الاستيراد العشوائي للتفاصيل الداخلية بين الوحدات.

## مكدس تقني مرشح

- TypeScript.
- Next.js للواجهة وواجهات HTTP عند اعتماد ذلك.
- PostgreSQL للبيانات العلائقية.
- Prisma أو ORM مكافئ بعد مراجعة الاحتياجات.
- Redis/Queue عند الحاجة للمهام الخلفية.
- Object storage للملفات، مع روابط موقعة قصيرة العمر.
- مزود مصادقة موثوق أو جلسات آمنة موثقة.
- مزود AI عبر واجهة موحدة تسمح بالتبديل دون ربط النطاق بمزود واحد.

هذه اختيارات مقترحة وليست dependencies مثبتة. يجب تسجيل قرار ADR قبل اعتماد الإصدارات النهائية.

## تدفق طلب نموذجي

1. المصادقة والتحقق من مساحة العمل.
2. التحقق من الصلاحية على مستوى المورد.
3. التحقق من payload باستخدام schema.
4. تنفيذ use case داخل معاملة عند الحاجة.
5. حفظ سجل النشاط/التدقيق.
6. إعادة استجابة لا تكشف بيانات حساسة.
7. الأعمال الطويلة تنشر job بمعرف idempotency وتنفذ في worker.

## مبادئ الاعتمادية

- timeouts لكل اتصال خارجي.
- retry محدود مع exponential backoff وjitter.
- circuit breaker للتكاملات المتعثرة عند الحاجة.
- idempotency للعمليات التي قد تتكرر.
- transactional outbox عند ربط المعاملات بأحداث خارجية.
- pagination cursor للبيانات الكبيرة.
- health/readiness checks ومراقبة الأخطاء.

## قرارات لم تُحسم

المصادقة، ORM، queue، التخزين، مزود الذكاء الاصطناعي، واستضافة workers. لا تُخفى هذه القرارات داخل الكود؛ توثق في ADR.
