# سجل قرارات التصميم (ADR Index)

سجل القرارات المعمارية يضمن أن تكون الاختيارات المهمة معلنة وقابلة للمراجعة.

## ADR-0001: البدء بمستودع نظيف وتوثيق النطاق
- **الحالة:** مقبول.
- **السياق:** المستودع عند بدء العمل يحتوي README قصيراً فقط ولا يحتوي تطبيقاً.
- **القرار:** تأسيس وثائق المنتج والمعمارية والبيانات والأمن وخارطة الطريق قبل إدخال إطار عمل أو خدمات خارجية.
- **النتيجة:** لا نفترض وجود بنية أو اعتماديات لم يتم التحقق منها.

## قرارات قيد الدراسة
- إطار الواجهة والخادم.
- ORM ومزود PostgreSQL.
- المصادقة وإدارة الجلسات.
- queue ومحرك الأتمتة.
- مزود الذكاء الاصطناعي وطبقة embeddings.
- تخزين الملفات وإدارة الأسرار.

لكل قرار لاحق: اكتب السياق والبدائل والاختيار والتبعات، وحدد إن كان القرار مؤقتاً أو نهائياً.
